# Python Functions & Modular Structure

Repositório de estudos em Python focado na transição de scripts lineares para **programação procedural modular**, utilizando funções (`def`), retorno de valores (`return`) e organização da execução com `main()`.

## Conceitos aplicados
- **Funções (`def`)**: divisão do código em blocos reutilizáveis com nomes descritivos em inglês.
- **Retorno (`return`)**: devolução de valores calculados ou processados para quem chamou a função.
- **Função `main()`**: centraliza o fluxo principal de execução do programa.

## Como executar localmente
1. Certifique-se de ter o **Python 3** instalado na máquina.
2. Clone ou baixe este repositório para o seu computador.
3. Abra o terminal na pasta do projeto e execute:
   ```bash
   python nome_do_arquivo.py
